# 动画实现逻辑详解

本项目中的动画系统采用了**基于进度值的插值方法**和**状态机模式**，实现了平滑的动画效果和复杂的动画序列。本文将详细解释所有动画系统的实现逻辑。

---

## 一、动画系统架构概述

### 1.1 核心设计理念

项目中的动画系统遵循以下设计原则：

1. **进度值（Progress）驱动**：所有动画使用 0.0 到 1.0 的进度值表示动画完成度
2. **时间累积**：通过 `deltaTime` 实现帧率无关的平滑动画
3. **线性插值**：使用 `进度值 * 目标值` 的方式进行线性插值
4. **状态机管理**：使用布尔标志和进度值组合管理动画状态
5. **可逆动画**：支持正向和反向动画（如地板翘起/恢复）

### 1.2 动画更新流程

所有动画在主渲染循环中更新，遵循以下模式：

```cpp
// 伪代码示例
if (animationActive) {
    progress = min(1.0f, progress + speed * deltaTime);  // 正向动画
    // 或
    progress = max(0.0f, progress - speed * deltaTime);  // 反向动画
    
    if (progress >= 1.0f || progress <= 0.0f) {
        // 动画完成，更新状态
    }
}
```

## 二、地板翘起动画系统

### 2.1 触发条件

地板翘起动画由两个马雕像的位置触发：

```1402:1422:main.cpp
        // 检测两个马是否都在对应的地砖范围内，触发地板翘起
        if (isHorse1OnTile1() && isHorse2OnTile2()) {
            if (!isFloorTileLifting) {
                isFloorTileLifting = true;
                std::cout << "触发地板翘起效果！" << std::endl;
            }
            // 更新翘起进度（0.0 到 1.0）- 正向旋转
            floorLiftProgress = glm::min(1.0f, floorLiftProgress + floorLiftSpeed * deltaTime);
        } else {
            // 如果马离开了触发区域，反向旋转回去
            if (isFloorTileLifting && floorLiftProgress > 0.0f) {
                // 减少翘起进度（反向旋转）
                floorLiftProgress = glm::max(0.0f, floorLiftProgress - floorLiftSpeed * deltaTime);
                // 当进度降到0时，重置状态
                if (floorLiftProgress <= 0.0f) {
                    isFloorTileLifting = false;
                    floorLiftProgress = 0.0f;
                    std::cout << "地板恢复原状" << std::endl;
                }
            }
        }
```

**触发机制：**
- **触发条件**：两个马雕像都位于对应的地砖范围内（`isHorse1OnTile1() && isHorse2OnTile2()`）
- **正向动画**：进度值从 0.0 增加到 1.0（地板翘起）
- **反向动画**：当马离开触发区域时，进度值从当前值减少到 0.0（地板恢复）

### 2.2 动画参数

```98:101:main.cpp
// 地板翘起相关变量
bool isFloorTileLifting = false;      // 地板是否正在翘起
float floorLiftProgress = 0.0f;       // 翘起进度 (0.0 到 1.0)
float floorLiftSpeed = 0.5f;          // 翘起速度
```

- **`isFloorTileLifting`**：动画状态标志
- **`floorLiftProgress`**：动画进度（0.0 = 未翘起，1.0 = 完全翘起）
- **`floorLiftSpeed`**：每秒进度增加量（0.5 = 2秒完成动画）

### 2.3 几何变换实现

地板翘起通过矩阵变换实现，使用进度值插值旋转角度：

```1584:1605:main.cpp
            // 计算翘起角度（最大90度）
            float maxLiftAngle = 90.0f;
            float liftAngle = floorLiftProgress * maxLiftAngle;

            // 设置模型变换：变换顺序（从右到左执行，代码从左到右写）：
            // 1. 平移到世界位置（地板块中心）
            // 2. 平移到旋转轴位置（前边缘的地板表面，z=tileHalfDepth, y=tileHalfHeight，作为支点）
            // 3. 绕x轴旋转（正角度，让后边缘向上翘起）
            // 4. 平移回中心（相对于前边缘地板表面的偏移）
            model = glm::mat4(1.0f);
            // 先平移到世界位置（地板块中心，使用与无盖长方体相同的全局变量位置）
            model = glm::translate(model, glm::vec3(g_tileWorldCenterX, tileWorldCenterY, g_tileWorldCenterZ));
            // 平移到旋转轴位置（前边缘的地板表面）
            // 局部坐标中，前边缘在z=tileHalfDepth=1.0，地板表面在y=tileHalfHeight=0.075
            // 支点应该在前边缘且在地板表面（不是地板块的中心y=0）
            model = glm::translate(model, glm::vec3(0.0f, tileHalfHeight, tileHalfDepth));
            // 绕x轴旋转（使用正角度，让后边缘向上翘起）
            // 旋转角度为正，使得后边缘（z=-tileHalfDepth）向上旋转
            model = glm::rotate(model, glm::radians(liftAngle), glm::vec3(1.0f, 0.0f, 0.0f));
            // 平移回中心（相对于前边缘地板表面的偏移）
            model = glm::translate(model, glm::vec3(0.0f, -tileHalfHeight, -tileHalfDepth));
            lightingShader.setMat4("model", model);
```

**变换流程：**

1. **角度计算**：`liftAngle = progress * maxAngle`（线性插值）
2. **旋转轴定位**：前边缘的地板表面作为支点（z=1.0, y=0.075）
3. **变换顺序**：
   - 平移到世界位置
   - 平移到旋转轴
   - 绕X轴旋转
   - 平移回中心

这种变换顺序确保地板块围绕前边缘旋转，实现"翘起"效果。

### 2.4 可逆动画特性

地板翘起动画支持**可逆动画**：
- 触发时：进度从 0 → 1（翘起）
- 取消时：进度从 1 → 0（恢复）
- 速度相同：正向和反向使用相同的速度值

## 三、书架移动动画系统

### 3.1 动画参数

```144:147:main.cpp
const float SHELF_MOVE_DISTANCE = 2.5f; // 书柜向z轴负方向平移的距离
bool shelfMoving = false;             // 书柜是否正在移动
float shelfMoveProgress = 0.0f;       // 书柜移动进度（0.0到1.0）
const float SHELF_MOVE_SPEED = 1.0f; // 书柜移动速度
```

- **`SHELF_MOVE_DISTANCE`**：移动距离（2.5 单位）
- **`shelfMoveProgress`**：移动进度（0.0 = 初始位置，1.0 = 最终位置）
- **`SHELF_MOVE_SPEED`**：每秒进度增加量（1.0 = 1秒完成动画）

### 3.2 正向移动动画

```2277:2292:main.cpp
        // --- 更新书柜移动动画 ---
        if (shelfMoving) {
            shelfMoveProgress = glm::min(1.0f, shelfMoveProgress + SHELF_MOVE_SPEED * deltaTime);
            // 计算新的书柜位置（向z轴负方向平移，即向后移动）
            float moveAmount = shelfMoveProgress * SHELF_MOVE_DISTANCE;
            shelfPosition.z = SHELF_INITIAL_Z - moveAmount; // 向z轴负方向平移（Z减小，向后移动）
            if (shelfMoveProgress >= 1.0f) {
                shelfMoving = false;
                // 书柜移动完成后，触发砖墙旋转
                if (!brickSquareRotating && !brickSquareRotatingBack) {
                    brickSquareRotating = true;
                    brickSquareRotationProgress = 0.0f;
                    std::cout << "书柜移动完成，砖墙开始旋转" << std::endl;
                }
            }
        }
```

**实现逻辑：**

1. **进度更新**：`progress = min(1.0, progress + speed * dt)`（限制最大值为 1.0）
2. **位置计算**：`newPosition = initialPosition - progress * distance`
3. **动画完成**：进度达到 1.0 时，触发下一个动画（砖墙旋转）

### 3.3 反向移动动画

```2294:2312:main.cpp
        // --- 更新书柜反向移动动画 ---
        if (shelfMovingBack) {
            shelfMoveProgress = glm::max(0.0f, shelfMoveProgress - SHELF_MOVE_SPEED * deltaTime);
            // 计算新的书柜位置（向z轴正方向平移，即向前移动回原位置）
            float moveAmount = shelfMoveProgress * SHELF_MOVE_DISTANCE;
            shelfPosition.z = SHELF_INITIAL_Z - moveAmount; // 向z轴正方向平移回原位置
            if (shelfMoveProgress <= 0.0f) {
                shelfMovingBack = false;
                shelfMoveProgress = 0.0f;
                shelfPosition.z = SHELF_INITIAL_Z; // 确保回到初始位置
                // 书柜反向移动完成后，重置马的累计旋转度数
                horse1AccumulatedRotation = 0.0f;
                horse2AccumulatedRotation = 0.0f;
                // 更新初始角度为当前角度，以便重新开始累计
                horse1InitialRotationY = horse1RotationY;
                horse2InitialRotationY = horse2RotationY;
                std::cout << "书柜回到原位置，动画序列结束，重置马的累计旋转度数" << std::endl;
            }
        }
```

**反向动画特点：**

- **进度递减**：`progress = max(0.0, progress - speed * dt)`
- **位置恢复**：使用相同的公式，但进度从 1.0 减少到 0.0
- **状态重置**：动画完成后重置相关状态，为下一轮动画序列做准备

## 五、动画序列系统

### 5.1 序列触发机制

动画序列由马的旋转角度触发：

```2246:2275:main.cpp
        // --- 检测马的旋转角度，触发动画序列 ---
        // 计算动画序列是否正在执行（任意一个动画状态为true即表示动画序列正在执行）
        isAnimationSequenceActive = shelfMoving || shelfMovingBack || brickSquareRotating || brickSquareRotatingBack || (brickSquareRotationProgress >= 1.0f && brickSquareRestTime < BRICK_SQUARE_REST_DURATION);
        
        // 只在动画序列未执行时记录旋转角度
        if (!isAnimationSequenceActive) {
            // 计算马1从初始角度转过的度数（处理角度环绕）
            float horse1CurrentRotation = horse1RotationY;
            float horse1Diff = horse1CurrentRotation - horse1InitialRotationY;
            // 将角度差归一化到[-180, 180]范围
            while (horse1Diff > 180.0f) horse1Diff -= 360.0f;
            while (horse1Diff < -180.0f) horse1Diff += 360.0f;
            horse1AccumulatedRotation = glm::abs(horse1Diff);
            
            // 计算马2从初始角度转过的度数（处理角度环绕）
            float horse2CurrentRotation = horse2RotationY;
            float horse2Diff = horse2CurrentRotation - horse2InitialRotationY;
            // 将角度差归一化到[-180, 180]范围
            while (horse2Diff > 180.0f) horse2Diff -= 360.0f;
            while (horse2Diff < -180.0f) horse2Diff += 360.0f;
            horse2AccumulatedRotation = glm::abs(horse2Diff);
            
            // 检查两个马的旋转是否都超过阈值
            if (horse1AccumulatedRotation >= HORSE_ROTATION_THRESHOLD && horse2AccumulatedRotation >= HORSE_ROTATION_THRESHOLD) {
                // 触发动画序列（与原先按下按钮相同的逻辑）
                shelfMoving = true;
                shelfMoveProgress = 0.0f;
                std::cout << "两只马都旋转超过45度，触发动画序列！书柜开始移动" << std::endl;
            }
        }
```

**触发逻辑：**

- **状态保护**：只在动画序列未执行时检测触发条件
- **角度计算**：处理角度环绕问题（将角度差归一化到 [-180°, 180°]）
- **阈值检测**：两个马都旋转超过 45 度时触发

### 5.2 动画序列流程

动画序列按照以下顺序执行：

```
1. 书架移动（正向）
   ↓
2. 砖墙旋转（正向）
   ↓
3. 静止阶段（2秒，箭矢发射）
   ↓
4. 砖墙旋转（反向）
   ↓
5. 书架移动（反向）
   ↓
6. 序列结束，重置状态
```

**状态转换链：**

每个动画完成时，会触发下一个动画的开始：

- **书架移动完成** → 触发砖墙旋转
- **砖墙旋转完成** → 进入静止阶段，启动箭矢系统
- **静止时间结束** → 触发砖墙反向旋转，停止箭矢系统
- **砖墙反向旋转完成** → 触发书架反向移动
- **书架反向移动完成** → 重置所有状态

### 5.3 序列状态管理

```2248:2248:main.cpp
        isAnimationSequenceActive = shelfMoving || shelfMovingBack || brickSquareRotating || brickSquareRotatingBack || (brickSquareRotationProgress >= 1.0f && brickSquareRestTime < BRICK_SQUARE_REST_DURATION);
```

**状态判断逻辑：**

`isAnimationSequenceActive` 为 true 当满足以下任一条件：
- 书架正在移动（正向或反向）
- 砖墙正在旋转（正向或反向）
- 砖墙处于静止阶段（progress = 1.0 且静止时间未结束）

这个标志用于：
- **防止重复触发**：序列执行期间不检测新的触发条件
- **状态同步**：确保动画状态的正确管理

## 六、动画系统设计模式总结

### 6.1 核心设计模式

1. **状态机模式**：使用布尔标志管理动画状态
2. **进度值模式**：使用 0.0-1.0 的进度值表示动画完成度
3. **线性插值**：通过进度值进行线性插值计算
4. **时间驱动**：使用 `deltaTime` 实现帧率无关的动画

### 6.2 动画更新模式

所有动画遵循统一的更新模式：

```cpp
// 正向动画
if (animating) {
    progress = min(1.0f, progress + speed * deltaTime);
    value = initialValue + progress * (targetValue - initialValue);
    if (progress >= 1.0f) {
        // 动画完成，触发下一个动画或重置状态
    }
}

// 反向动画
if (animatingBack) {
    progress = max(0.0f, progress - speed * deltaTime);
    value = initialValue + progress * (targetValue - initialValue);
    if (progress <= 0.0f) {
        // 动画完成
    }
}
```

### 6.3 优点与特性

1. **平滑动画**：基于时间的更新确保不同帧率下的一致性
2. **可逆动画**：支持正向和反向动画，实现交互式效果
3. **状态清晰**：使用标志和进度值组合，状态管理清晰
4. **易于扩展**：统一的模式便于添加新的动画
5. **性能优化**：简单的计算，性能开销小

### 6.4 注意事项

1. **进度值限制**：使用 `min/max` 确保进度值在 [0, 1] 范围内
2. **状态同步**：确保动画状态标志与进度值的一致性
3. **触发保护**：使用 `isAnimationSequenceActive` 防止重复触发
4. **角度处理**：旋转动画需要处理角度环绕问题

## 总结

项目中的动画系统展现了清晰的架构设计：
- **统一的实现模式**：所有动画使用相同的进度值和时间驱动模式
- **灵活的状态管理**：通过状态机模式管理复杂的动画序列
- **平滑的视觉效果**：基于时间的更新确保动画的流畅性
- **良好的扩展性**：统一的模式便于添加新的动画效果

这种设计使得动画系统既易于理解和维护，又能实现复杂的动画序列效果。
