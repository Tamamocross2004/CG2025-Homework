# 灵珠与木板翘起功能逻辑说明

## 触发机制
- **触发条件**：当两个马模型同时移动到房间z轴尽头（z坐标 ≥ 3.0）时触发木板翘起效果
- **退出条件**：当马离开触发区域时，木板自动反向旋转回原位

## 木板翘起效果
- **位置**：房间右侧（X: 2.0-3.5, Z: -1.5-0.5）的一块地板
- **旋转方式**：绕前边缘（地板上表面）作为支点，向上旋转最大90度
- **动画**：平滑旋转，进度从0.0到1.0，旋转速度由`floorLiftSpeed`控制
- **主地板处理**：翘起木板在原始地板上的投影区域会被排除（形成洞）

## 无盖长方体
- **位置**：位于翘起木板下方，与投影区域对齐，向下延伸到地板下方（Y: -2.85 到 -3.5）
- **尺寸**：宽度1.5，深度2.0，高度0.65
- **纹理**：使用地板纹理

## 灵珠系统
- **位置**：放置在无盖长方体内部中心
- **外观**：彩色发光球体，颜色随时间动态变化（RGB循环）
- **光照效果**：
  - 灵珠作为点光源照亮无盖长方体内部
  - 光源强度：8.0
  - 地板的强度倍数为5.0（特别增强内部亮度）
  - 使用宽松的衰减公式扩大光照范围

## 拾取机制
- **交互提示**：靠近灵珠时显示"E"键提示
- **拾取操作**：按E键拾取（必须在未拾取且木板翘起状态下）
- **拾取效果**：
  - 灵珠消失（永久不渲染）
  - 灵珠光照立即关闭
  - 屏幕中央显示"ORB PICKED!"消息（黄色边框，半透明黑色背景）
  - 消息显示3秒，带淡入淡出效果
- **优先级**：E键优先检测马的控制，只有在不靠近马时才检测灵珠拾取

## 交互优先级
1. 如果靠近马雕像 → 进入/退出马的控制模式
2. 如果不靠近马且靠近灵珠 → 拾取灵珠
3. 拾取灵珠后仍可控制马模型

## 相关变量
- `isFloorTileLifting`：是否触发翘起效果
- `floorLiftProgress`：翘起进度（0.0-1.0）
- `orbPicked`：灵珠是否已被拾取
- `showOrbPickupMessage`：是否显示拾取消息
- `Z_AXIS_THRESHOLD = 3.0f`：z轴触发阈值
- `INTERACTION_DISTANCE = 3.0f`：交互距离阈值
